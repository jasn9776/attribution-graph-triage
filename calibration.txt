RATING CRITERIA — attribution-graph-triage, Day 5
Fixed after ten practice graphs drawn from outside the rated sample, before any rated graph
was seen.

APPLY IN THIS ORDER

Check the 0 conditions first. "Restates the prompt" is about CONTENT and overrides the 1
conditions, which are about naming: a path whose content reduces to "the token appeared
earlier" is a 0 however its features are labelled. Then the error rule, then the label
rule, then the 2 checks.

0
No cross-position edge AND no named intermediate;
OR the feature the explanation depends on has an error node as its largest input;
OR the explanation restates the prompt (a token repeated, a space before a year, an
article expected).

1
A named feature I can read but no path to the logit;
OR a complete path whose intermediate I cannot name, including when the label is vague or
implausible for the position it sits on (record the label in the note);
OR a real named intermediate that sits only at the read-out position, with no crossing.

2
An interpretable intermediate feature built at a CONTENT position — one that says
something the prompt does not — carried by a cross-position edge into a feature at the
read-out position that feeds the logit.
Both are required. A crossing without an intermediate is routing, not computation: raw
token embeddings reaching the logit from earlier positions. An intermediate without a
crossing is the final token elaborating itself, which the prompt largely implies already.

RULES FOR THE HARD CASES

Check before 2      NECESSARY, NOT SUFFICIENT. The trace footer reports at least one
crossing, AND a named feature sits at a non-final position. After
both pass, the error rule and the label rule still apply.

~~Crossings           Only FEATURE-to-FEATURE edges across positions are marked * and count
toward the check. A token embedding reaching a later position is the
residual stream carrying the raw token, not transported computation.~~

Error               A feature is unreadable when an error node is its largest input, or
when error nodes are most of its inputs. Error elsewhere in the tree
does not disqualify it.

Labels              A label counts as naming only if it is specific and plausible for the
position it sits on. A label that merely contains the predicted word
is not an intermediate unless something upstream produced it.

Influence           Magnitude is not part of the rating: a complete named chain is a 2
however small its weights. Weak chains, and chains smaller than the
direct token-to-logit edge, are flagged in the note and split out on
Day 6.

Naming              Strict. A 2 requires naming the intermediate, using the Neuronpedia
description.
